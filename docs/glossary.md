# Paseo coordination

Terms for collaboration around the user’s goals and project work. Existing Bot terms describe the current assistant and its conversations.

## Language

**Paseo Team**:
Goal-oriented collaboration organized by one continuing Coordinator and task-specific Project Agents, which may work across projects. Its membership and responsibilities follow the task rather than a fixed team structure.

**Coordinator**:
The continuing owner of coordination toward the user’s goals and the user’s main conversational contact. It brings together project findings and progress, handles feedback, and maintains follow-through as the work changes.

**Role**:
A responsibility represented by an Agent preset, distinct from the particular Agent created or reused for a task.

**Paseo Bot**:
The existing user-facing assistant for continuing coordination toward the user’s goals. In the Paseo Team product discussion, Bot is the default Coordinator role.

**Project Agent**:
An Agent responsible for project-grounded investigation, judgment, and concrete execution, created or reused according to the task.

**Goal conversation**:
An independent conversation with a Coordinator about a user’s goal. Its goal context remains distinct from other goal conversations.

**Bot conversation**:
The existing name for a goal conversation with Paseo Bot. Delegated project Agents are not Bot conversations.

**Bot workspace**:
The dedicated workspace for Bot conversations on a host.

**Project**:
A body of project work associated with a directory root in Paseo.

**Host**:
The daemon connection target that owns the workspace and its conversations.

**Draft**:
Unsent text intended for a conversation.

**Archive**:
The lifecycle action that removes a conversation from active work while retaining its history.

**Delegated Agent**:
An Agent assigned concrete work by a Coordinator in a target project workspace, distinct from the coordinating conversation.
