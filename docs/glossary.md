# Glossary

- **Paseo Bot** — The user’s assistant and the continuing owner of coordination toward the user’s goals. It connects the user with project Agents and remains responsible for keeping work aligned as goals and circumstances evolve.
- **Project Agent** — An Agent responsible for project-grounded investigation, judgment and concrete execution.
- **Bot conversation** — One independent Paseo Agent session in an explicitly opened native Bot workspace generation, or registered by the legacy Bot page. Delegated child Agents are excluded.
- **Bot workspace** — Dedicated background workspace whose shared working directory is `~/.paseo/bot/` on its daemon host.
- **Project** — Paseo's record for a selected directory root; the daemon may create it automatically for the Bot workspace.
- **Host** — Connection target for the daemon that owns the Bot workspace and its conversations.
- **Draft** — Unsent text. Native chat owns new and existing conversation drafts. Legacy Bot conversation drafts are not migrated.
- **Archive** — Paseo's existing lifecycle action; archived Bot conversations remain accessible through History. Native chat determines their available actions.
- **Delegated Agent** — Agent assigned work from a Bot conversation and placed in its target business workspace. It is not another Bot conversation.
