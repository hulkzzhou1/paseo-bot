# Issue tracker

Use GitHub Issues in `hulkzzhou1/paseo-bot`, with explicit `--repo hulkzzhou1/paseo-bot` and multiline bodies via `--body-file`.

The specification is the parent issue. Implementation tickets are native sub-issues with native blocked-by relationships. Apply `ready-for-agent`; only start tickets whose blockers are complete.

Triage labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`.

Product discussions in upstream Paseo are context, not implementation authorization or upstream acceptance. Keep this plugin's implementation work in this repository.
