# Issue #5: archive and explicit workspace rebuild

Base revision: `c6240c5`, branch `implement/issue-5`. Runtime target remains installed app/daemon/CLI/public SDK **0.13.2**. Independent Standards/Spec review and desktop/mobile actual browser acceptance are root-owned and remain pending this implementation record.

## Behavior and public boundaries

- Archive validates exact Bot installation/session/workspace ownership, stops an active turn through the existing public CLI, refreshes until Stop is confirmed, then archives through the public Agent handle and checks its final `archivedAt`. Refused/unknown Stop prevents archive. Drafts and ordinary directory files are retained. Archived conversations expose read-only history with no send, permission response, rename, unarchive or delete controls.
- History provides active/archived views using the existing ordered cursor pages. Old generation references remain in owned metadata. Selecting or restoring an archived conversation displays the actual durable Paseo transcript; starting a new conversation does not copy its context.
- Workspace inspection distinguishes actual archive evidence, successful resource absence, and errors/timeouts. The public `workspace.archived` hook records exact owned workspace identity/time. If the hook was missed, durable read-only recovery inspection identifies archived versus missing resources; no restore/unarchive API is called.
- The high-level SDK only lists active workspaces. The public low-level driver offers `inspectWorkspaceRecovery`, but importing public `@getpaseo/server/daemon-control` directly into the plugin's compiled CJS entry failed at runtime because a dependency uses `import.meta` (`filename ... Received undefined`). The shipped `server/recovery-probe.mjs` therefore stays ordinary ESM. The server discovers its own installed absolute source directory through public selected-home `paseo plugin ls`, validates the exact plugin identity/path, and launches the packaged helper with `process.execPath` and argv. The helper uses normal public `@getpaseo/client/node` and `@getpaseo/server/daemon-control` imports, authenticates only the exact inherited selected instance via the public local-credential API, returns classification only, and closes its connection in `finally`. `@getpaseo/server@0.13.2` is a locked runtime dependency for this asset; there is no private host import or direct private-store inspection.
- Explicit Rebuild persists a replacement-generation identity before side effects, then creates that exact new background workspace using public `workspaceId` and an idempotency key derived from the old exact workspace. Concurrent clicks reuse one replacement. The old workspace stays archived, old conversations remain referenced, and the same ordinary Bot directory/files are retained. A failed inspection never authorizes rebuild.
